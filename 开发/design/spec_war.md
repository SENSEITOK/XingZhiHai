## 0. 结论

1. **补一层「所属」`run.org`，并给两个闪灵开局装上 `OP_SETUP`。** 现在 linshigong77 和 paiqian77 没有 setup：白身，没营生，没所属，侧栏还叫一个存款 900 的派遣工去招兵。装好之后，她进门就是「闪灵博物馆·文创办·临时工」或「闪灵博物馆·海洋展馆·派遣」，有营生、有科层、有本季名额动员的钩子。法术和天赋归 spec_spells 管，本稿只管与战争有关的字段。
2. **馆战（岛群内战）不另起炉灶，在 P243 `run.mw` 上加一个 `kind:"guanzhan"`。** 会战还走 `mwBattle`，和谈还走 `mwTreaty`，裁定者还是 `battle` / `parley` 两种 kind，只在 JSON 里加三个可选字段 `op` / `to` / `dip`。新增的东西有：
   - 阵营（领头的一家加盟友；成员可以出局、倒戈、被抢走名额）
   - 战备→战争两个阶段，周日结算，俘虏比例
   - 四个岗位（前线／后勤／外交／笔杆子）和「外交权」
   - 外交动作（结盟／倒戈／倒戈一击／挑拨／赎俘）
   - 决斗代打（合法决斗权）
   - 「当局风声」和反恶意竞争法的几条硬约束
   - 和约按各馆的脾气出条款（石村不出钱只给藏品，亮片不割地）
   - 名额落袋，年底冬季授勋日结算
3. **馆内斗也是同一个引擎的 `kind:"feud"`。** 对手是闪灵自己的展馆或办公室，罚则是申饬、罚金、罚酒三杯，不惊动当局。外战一开，内斗自动停（77:38298-38304）。
4. **掠夺战争是一个新的出阵变体 `raidGo`。** 它复用 `armySortie` 的 d20 四档，加上：
   - 战场与目标（储藏点／运输线／前哨站／工厂；1994 另有城镇／金库／卷轴库）
   - 三种兵力：自家仆从军、馆里的小队、私掠委托
   - 准入：开拓异界权力、开发权或私掠委托，没有就是无照，涨监管会风声
   - 13% 兵饷、2-4% 运输损耗、5% 以上吃官司
   - 战利去向：藏品入包（带 `cang:1`，对上 spec_isle 的展馆陈列）、货物、现钱、宣称地
   - 报复袭击，接 spec_isle 的 `isleDef`、`warHeat`
5. **1994 的「内战」有正典可做，走两条路。**
   - **魔女之乱**：三年一次的「奉旨造反」，6-7 月在盖亚开打。交保证金报名，被俘就出局，抓到的俘虏换勋章，勋章换龙宠和卷轴。
   - **欧陆内战外援**（三岛内战、勃艮第内战）：只放一个机会钩子，引擎层不新增东西。

   南城的「内战年代」是两百年前的史事（94:5594-5619），只做古迹和传闻，不做成可玩，理由见 §8.3。
6. **其他开局都有入口**，见 §8.4 的矩阵。几个例子：weida77 被请去恩怨局代打，zhanmo77 签雇佣兵魔女合同，saibo 走星海开拓登记去掠夺，shengnv 在盐白之地打领主战争，shixun 开局那年正赶上魔女之乱。
7. **数值上不让临时工靠战争暴富。**
   - 她拿的主要是这些：公分（又能换法术，和法术那一题连上）、军功、科层晋升、授勋名单、奖金，加上偶尔一件 MVP 藏品。
   - 赔款进馆里账上，她只按岗位拿 2-4%。
   - 模拟结果（§11）：一场秋季馆战，从领头的那家抢到名额的概率约 0.6-0.75；在乱斗里专挑有名额的馆打，平均能抢 1.6 个；当局介入的概率约 0.3-0.4。原著是「输掉 4 个名额，当局叫停」（77:33803-33811），量级对得上。
8. **顺手修五个 bug**：
   - `run.lastWar` 设了以后从来不清，导致每一幕都在注入上一场出阵；
   - `MW_KNOWN` 认不出「寂静馆」；
   - 赔款全额进她的钱包；
   - 「割地免谈」无条件出现；
   - 出阵折损把驻防在外的兵也算进去扣。

   详见 §1.3。

## 2. 设计总览

```
                 ┌────────────── run.org（所属：哪个馆／公司／阵营，哪个部门，什么身份）──────────────┐
                 │                                                                                │
   run.mw.kind ─ guanzhan 馆战（岛群内战）  ─ feud 馆内斗  ─ luan 魔女之乱（1994–2059）  ─ plain（P243 原样）
                 │   会战 mwBattle（+岗位、阵营、周日、俘虏）     │                │
                 │   和谈 mwTreaty（+条款、名额、去向）          │                │
                 │   外交 gwDip（结盟/倒戈/一击/挑拨/赎俘）      │                │
                 │   决斗 gwDuel（合法决斗权／代打）             │                │
                 └──────────── run.gw（周结算、当局风声、名额账、停战、盟约、掠夺热度、授勋）────────┘
   掠夺 raidGo ─ 战场（异界馆属世界／位面交战区／异界地界）× 目标 × 兵力（自家／馆里／私掠）→ 战利去向 → 报复
   共用：warRoll（d20 四档）、armySortie 的折损口径、pwWar、polAdd、meritGain、pwMedalAward、bagPut、psGoodsAdd、spec_isle 的 isleDef/isleHaul/isleScout/isleVault
```

**原则**

1. **骰子归引擎，正文归 AI。** 胜负、俘虏比例、条款、钱数都由引擎定，AI 只照档写。这和出阵、P243 是同一条规矩（≈27733 那一段）。
2. **临时工是馆里的一颗螺丝。** 馆里的兵归馆长调，她能做的是三件事：选岗位、拿外交权、在决定性的那一手上掷骰。奖励按她的贡献 `c` 和科层发，**不拿整笔战利**（77:32850-32864：外交大使拿到全部优势、守住胜利成果；77:33471-33487：外交权是「自主裁定俘虏与藏品怎么换」）。
3. **原著的规矩做成硬约束。**
   - 宣战要有借口（77:33033-33037）；
   - 俘虏只关一周，周日 0 点结算（77:33524-33533）；
   - 保护地不能抢（77:45031-45033）；
   - 当局可以叫停（77:33808-33815）；
   - 「当局的家人」要先拿许可（77:44072-44085）；
   - 首先挑事的一方吃通报批评（77:33798-33799）。
4. **不写死人。** 魔女被打倒等于被俘，一周带薪假（77:33525）；凡人平民不入镜（77:33176-33179）；人不能当战利品；未成年人和外形幼小的人不上战场（§9.4）。
5. **老档零迁移成本。** 老档里没有 `kind` 的 `run.mw` 一律当 `plain`，P243 的行为一字不变。

### 4.3 星期和周号

现在 `clockAdd` 和 `turnEnd` 都按「一个月 30 天」推日子，所以不能用真实日历算星期。

```js
function gwDayNo(run) { const c = run.clock || { m: 5, d: 12 }; return ((run.year || 1994) * 12 + ((c.m || 1) - 1)) * 30 + ((c.d || 1) - 1); }
function gwDow(run)    { return ((gwDayNo(run) + (gwOf(run).dowOff || 0)) % 7 + 7) % 7; }   // 0 周一 … 6 周日
function gwWeekNo(run) { return Math.floor((gwDayNo(run) + (gwOf(run).dowOff || 0)) / 7); }  // 周日 24 点进下一周＝结算
function gwSetDow(run, dow) { const g = gwOf(run); g.dowOff = ((dow - gwDayNo(run)) % 7 + 7) % 7; g.wk = gwWeekNo(run); }
```

**「日期：」行**（≈28180）的正则再认一个可选的星期，写法是 `（周日）` 或 `星期日`：

```js
const dw = v.match(/(?:周|星期)([一二三四五六日天])/); if (dw) stat.clock.dow = "一二三四五六日天".indexOf(dw[1]) % 7;
```

结算端（≈28673）在设好月日之后，`if (stat.clock.dow != null) gwSetDow(run, stat.clock.dow)`。这样 AI 只要写一次星期，引擎就对齐了。**对齐只改 `dowOff`，不倒回已经结算过的周。**

### 5.2 怎么开战：三条路，都过「借口」这一关

**借口（cb）**：反恶意竞争法给「不宣而战」打了补丁（77:33033-33035）。闪灵的惯用手法是先打对方的盟友，等对方正式参战（77:33036-33037），或者往上报「可能有摩擦」（77:33041-33043）。

| cb | 什么时候成立 | 额外风声 |
|---|---|---|
| 名额 | 秋季（9-11 月），对方今年还有名额 | 0 |
| 盟友受攻 | `gw.pacts` 里有 X，并且 X 的仇家（名册 `enemy`）就是对方，或者对方最近打过 X | 0 |
| 报复 | `gw.hitBy[对方] ≥ 本周 − 8` | 0 |
| 妨碍公务 | 最近 4 周她（或馆里的小队）在对方出没的世界打过掠夺（77:33107「妨碍我馆公务的武装集团」） | +5 |
| 当局许可 | 对方是 `jia`；并且她科层 ≥ 5，或这是馆里秋季动员定的目标。许可费由馆里出（77:44539-44541），只记一笔 | 0（有许可，打 jia 不另涨风声） |
| （无） | 以上都不成立 | **不宣而战**：风声 +25，当场申饬；这场仗**抢不到名额**（无效） |

**三条路：**

1. **AI 写 `战役：我方｜对方｜缘由`**（已有）。`mwStart` 先用 `gwKindOf(run, a, b)` 判定种类：
   - 双方都在名册里 → `guanzhan`；
   - 双方都是同一个馆的展馆或办公室（`GW_HALLS`）→ `feud`；
   - 其余 → `plain`。

   有 `run.org` 并且我方写「我方」或空着时，我方取 `org.nm`，这个缺省值只对有所属的人生效。借口由 `gwCbOf(run, foeId, 缘由文字)` 推断：先看成立条件，再看缘由里的关键词，比如「名额」「报复」「盟」。推不出来就记「无」。

   `starter` 缺省为 1：写在前面的「我方」就是先动手的一方，和 P243 的语义一致。缘由里有「反击」「被打」「被偷袭」「报复」「自卫」时记 0。所以 AI 开的一场普通馆战，起始风声是 10 + 10 = 20。
2. **她在军略板递请战书**：`gwPetition(run, foeId, cb)`。
   - 科层 ≥ 6（正科，展馆主任一级），或者她自己就是 `company` 的社长：直接开战，`starter=1`。
   - 其余人员要过一次核准：

     ```
     d20 + ⌊政治资本/5⌋ + ⌊军功/4⌋ + ⌊口碑/20⌋ + (秋季动员期 ? 10 : 0)  对  15
     ```

     准了就开战，`starter=1`，依据是秽心报备枯华、枯华批复「好好干」（77:33107-33117）。驳回就来信「驳回」，4 周内不能再递。
   - 在核准之后、开战之前还要看借口：借口是「无」时，只有科层 ≥ 6 的人能「硬上」，后果是风声 +25。
   - 结果写进 `gw.last`，下一幕注入【馆战裁定·引擎已定】。输入框预填「向枯华递请战书：……」，让 AI 去写这一幕。
3. **秋季动员（引擎）**：`run.org.id === "shanling"` 并且年份 ≥ 2077。
   - 每年 9 月第一次周结算：来信，标题「秋季名额动员」；发 `opOpp`；设 `gw.mobY = 年`。动员期内请战核准 +10。
   - 到秋季第 3 周（9 月第 15 天起的第一个周结算）还没开馆战、`org.mob === 1`、今年战役数还没到两场时，`gwAutoWar(run)` 替馆里开战：
     - 对方从「受害人清单」挑（77:32899-32966）：名册里 `quota=1`、`bloc` 是 anti 或 mid、势 ≤ 5、今年没被抢、也不在停战期的馆。
     - 头一年固定石村（原著首选）；以后按 `U.hash32("gw"+年)` 挑。
     - 借口记「名额」，`starter=0`（这是馆里的仗，通报批评不算她的）。
     - 她的岗位取缺省值（§5.5）。
   - 不想参战的玩家可以在军略板关掉「随馆参战」（`org.mob=0`）。待定问题 1。

**通用守门**：
- 沿用一年至多两场战役、同时只打一场；
- 停战期内不能对同一家开战：`gw.truce[id] > 本周` 时，请战和 AI 的战役行都驳回，并给 `_nudge`；

### 5.3 阵营与「势」

- **开战时组阵营**：
  - 我方是 `org` 的那家馆。黑森、胧月**不自动**入阵：原著第一次大乱斗闪灵是单打（77:33783-33806），这两家到第二次才同盟（77:44943）。她要拉，得靠「结盟」。
  - 对方是领头那家，加上名册里它的 `allies`，最多 2 家。石村带亮片。
- **有效势**：

  ```js
  function gwEff(side) {                                   // side＝blocs.me / blocs.foe
    const act = side.filter(m => !m.out); if (!act.length) return 0;
    const lead = act[0], rest = act.slice(1).reduce((s, m) => s + m.str, 0);
    return Math.min(lead.str + 3, lead.str + Math.floor(rest / 4)) - (lead.cut ? 1 : 0);
  }
  ```

  `w.meStr` 和 `w.foe.str` 保留原值不动，给老代码和提示词用。会战改用 `gwEff`。

- **乱斗升级**：
  - **当局风声第一次 ≥ 40**：从名册挑 1-2 家 `bloc:"mid"`、`quota=1`、不在阵中的馆，加进对方阵营，各自开一条小战线，`hp = str`。依据：五六十家馆卷入（77:33799）。
  - **她签了盟约，盟友的仇家就入阵**：比如和水晶湖签了，哈根菲尔德马上入阵。依据：77:33801-33803。
  - 升级只发生一次（`w.esc`）；加的馆写进 `mwLog`。

### 5.4 阶段与周结算

**阶段**：开战时是「战备」。第一次会战，或者开战后的第一个周结算，转为「战争」，annal 记一句。依据：枯华宣布进入战争阶段、要评估报告（77:33453-33465）。

**`gwTick(run)` 何时调用**：时钟推进之后（≈28673 那段结尾），以及 `turnEnd` 的结尾。周号前进几周就补跑几次，每次至多补 8 周。

每次周结算（周日 24 点）做这些事：

1. **俘虏放回一半**：`capt.ours`、`capt.theirs` 各 ×0.5（向下取整）。依据：阵亡魔女一周不上班（77:33525）。
2. **她本人被俘的处理**：
   - 外交岗：下一次结算就放回（77:44888-44896）。
   - 周日被俘的：要过两次结算才放（77:33528-33533）。
   - 其余：过一次结算就放。
   - 放回时清 `w.cap`，去掉状态「重伤倒地」，`mwLog` 记「放回来了」。
3. **对方反击**（只在「战争」阶段）：

   ```
   d20 + 2 × (对方有效势 − 我方有效势)  ≥ 14
   ```

   成立时战局 −1，`gw.hitBy[领头] = 本周`。她的岗位是后勤时，阈值改为 15。
4. **当局风声**：先 −6；进入「战争」阶段满 3 周后，每周改为 +15（当局失去耐心）。
5. **门槛检查**：风声 ≥ 60 发申饬（§5.7）；≥ 90 当局介入。
6. **运输线复位**：被截的 `cut` 清零。
7. **掠夺热度**：每 4 周 −1。
8. **内斗热度**：−5。
9. **魔女之乱的窗口**（§8.1）。
10. **季度初「权力周期表」**：1、4、7、10 月第一次结算时发。来信写「新季度第一二周文创办最有权」，这两周文创办在内斗里势 +1。依据：77:26717-26739。
11. **秋季动员**（§5.2）。

**星期效果**：
- 当天是周日，会战和闪击都 +1 档差；得胜以上时，俘虏比例再加 5。依据：对面魔女都下班了，加班的人喊同事回来要耽误一两个小时，异界那边已经过了半天（77:33152-33156）。
- 提示词里写一句「今天周日」。

### 5.9 冬季授勋日（年结，`gwYear` 放在 `gclassTick` 之前）

授勋日在冬季（77:32797-32798）。年结跨过 12 月时，按**上一年** `gw.quota` 结算：

1. **别的前线**：这一年有过馆战时，`off = 0..2 随机`，她这一线最后战局 ≥ 3 时再 +1，上限 3。依据：闪灵同时在很多世界里打（77:44829-44830），总共拿到 5 个（77:33803-33806）。没打馆战时 `off = 0`。
2. **总数** `total = 1（自有）+ won + off`。
3. **她的贡献 c**：

   ```
   c = 本年战役军功合计 + 岗位分(外交3/前线2/后勤1/笔杆子1) + ⌊政治资本/10⌋ + ⌊口碑/25⌋ + (名下展馆 Lv≥2 ? 1 : 0)
   ```

### 7.4 掷骰、折损与损耗

```
敌情 foe = clamp(战场凶险 + 目标def − 2 − 情报1 − (观星台≥3 ? 1 : 0), 1, 7)
档差 dang = 军势档 + 阵型mod + 士气mod − foe + 江湖9级 + 周日 + (前线岗且馆战中 ? 1 : 0) + easySortieMod()
骰子 warRoll(dang)
```

- **情报**：可选，花 `目标价值 × 纪元 × 10%`，敌情 −1。依据：情报大约值一个小世界价值的一成（94:86204-86214）。观星台对 spec_isle 的 `isleScout`。
- **进账**：`V = 目标价值 × 纪元 × [0,.4,1,1.6][band] × TF[军势档]`，其中 `TF = [.4,.5,.8,1.1,1.5,2,2.6]`。
- **折损**：用掠夺表 `[.20,.10,.05,.02][band] × (1 + 阵型风险×.12) × easyLossMul()`，大约是出阵的六成，因为掠夺专挑软处下手（77:33187-33193）。基数是 `u.n − 驻防`。
- **运输损耗**：
  - 得胜以上：2-4%（随机）；苦战：5-8%。
  - 后勤岗 −1；`isleHaul(run)`（停鸡坪、港桥）再减。
  - 损耗 ≥ 5% 时来信「运输损耗超标」，罚款 1% V。依据：2-4% 算正常，5% 起有人起诉（94:84300-84305）。
- **兵饷**：用自家兵时扣 13%（94:84345），士气 +2。巨猫灯在场时，宝石先归猫：这一次的藏品品质降一档（94:84346）。
- **2077 洗白**：藏品和货当场出手时打七五折，走海蚀的渠道（77:44548-44551）。入包的不打折。

**宣称地年入**：`incomeOf` 新增一项 `clm = Σ round(v × .06 × f × 纪元)`，计入 `total`，返回值多一个字段 `clm`。账房那一行写成「宣称地 ×N」。
- 年结时 `f` 在 ±20% 之间重掷，夹在 [.5, 1.5]。依据：宣称地的价值随资源产出浮动，像一种自由货币，当局不承认（77:45023-45029）。
- 报复袭击优先抢宣称地，因为宣称地谁都可以抢（77:45031-45033）。

### 7.6 后果

- **掠夺热度**：`gw.rh[战场键] += [1,1,2,3][band]`（抢得越狠，结仇越深）。对方是名册里的馆时，`gw.hitBy` 记一笔（对方以后可以拿「报复」当借口）。
- **报复袭击 `gwRetaliate`**：
  - 馆战进行中每周掷一次，概率 `min(.4, .05 × Σrh)`；平时年结掷一次，概率 `min(.5, .08 × Σrh)`。
  - 打谁，依次挑：
    1. 她的宣称地：丢一块。
    2. 她的折叠空间：`garTier < 凶险` 时 `x.halt = 年`；否则驻军折 5%（`garLose`）。
    3. 她的空岛：交给 spec_isle 的袭岛事件处理，本系统只提供 `warHeat`。
    4. 她包里的藏品：没有展馆 Lv3（`isleVault`）时丢 1 件；有就只丢一半的概率。
  - 用馆里小队打的仇，记在馆账上，不打她，改成「馆战中下次会战 −1 档」。
  - 她的 MVP 藏品在半路上，10% 被隔壁展馆截走（77:32934）。后勤岗或者有停鸡坪时免。
- **当局与监管会**：
  - 馆战外的掠夺不涨当局风声；
  - 打 `jia`（当局的家人）照 §5.7 涨风声；
  - 无照照 7.1 涨监管会风声。
  - 监管会风声 ≥ 60：来信要求补登记、罚款 ¥2000 × 纪元；≥ 90：这一年不能再无照掠夺。
- **给 spec_isle 的接口**：

  ```js
  function warHeat(run) {                  // spec_isle §3.1 的袭岛概率加项：0–.12
    const g = run.gw || {}, live = run.mw && !run.mw.done && run.mw.kind === "guanzhan" ? .06 : 0;
    const rh = Object.values(g.rh || {}).reduce((a, b) => a + b, 0);
    return Math.min(.12, live + .02 * Math.min(3, Math.floor(rh / 2)));
  }
  ```

  另外：`isleHaul` 减运输损耗，`isleScout` 降敌情，`isleDef` 给报复袭击空岛时加档，`isleVault` 管藏品减损。缴获的藏品一律带 `cang:1`。

### 7.7 和现有系统的关系

- `armySortie` 不改玩法，只修 B5、抽出 `warRoll`。
- 出阵表单（≈30330 那一段）**不加**目标下拉。掠夺是单独一块（§10.2），免得两种结算搅在一起。
- 「AI 不能自己宣布出阵结果」这条规矩（≈27733 附近那一行说明）同样适用于掠夺。AI 只有两条路：裁定者 `op:"劫掠"`（§9.2），或者玩家点按钮。

### 8.2 欧陆内战外援（1994–2059，P3）

- **原著**：欧洲魔女的局部内战一再爆发，仆从军一天能死几千万，魔女和女巫享受战俘待遇（94:14647-14670）；三岛内战、勃艮第内战正在打（94:15450-15451）；有笑话说两个魔女吵架，各派仆从军去打（94:18095）。
- **做法**：她人在英伦或欧陆（`run.place` 是 yinglun 或 oulu）、年份 < 2060 时，每年发一封「外援招募」`opOpp`，发信方随机选「三岛某家」或「勃艮第某家」。AI 写 `战役：某家｜某家｜外援` 就走 `plain`。
- **提示词加两句**：
  - 「外援按周领佣金：她写 所属：某家｜外援｜佣兵 后，引擎每周发 ¥600×纪元」；
  - 「欧洲战场上只有魔女有战俘待遇，仆从军伤亡惨重，镜头不写细节」。
- 引擎层**不新增**东西，只加一个周薪钩子（`org.kind==="merc"` 的 `contract.fee` 在 `gwTick` 里每周发）。

### 8.3 南城「内战年代」为什么不做成可玩

- 那是两百年前统一战争时的史事。南城靠空岛岛链撑了 16 年围攻，最后和平解放（94:5594-5619）。如今岚海关成了休闲中心，缺口留作古迹（世界书 3513）。1994 年的玩家人在战后的南城，没有一场「正在打的南城内战」可以参加。
- 它最有价值的是**防守学说**：先切防御连线，否则魔女换防的速度比任何种族都快（94:5607、5612）；攻方至少要守方十倍兵力（94:648）。这一条吸收进馆战的「截运」（切运输线会让对方势 −1），以及空岛的「世界闸」（spec_isle 后续候选）。
- 做成古迹：南城区图上「岚海关缺口」加一条传闻，作为 spec_isle 或世界书的小项，不在本题范围。

### 11.2 模拟结果（`design/tools/gw_sim.cjs`，每组 20000 局）

模拟的是闪灵（6）对石村（5）加亮片（3）的一场秋季馆战。

- 每周 2 仗；周日占比 30%；她的交际调整值 +3。
- 她自己掷骰的四档分布按 `[.15,.30,.35,.20]`，对应 4 级角色打 DC 13。
- 外交权：每周争一次（d20+3 ≥ 15），拿到后试着策反亮片。
- 战局 ≥ 3 时开谈；风声按 11.1 的数。

| 打法 | 平均周数 | 平均抢到名额 | P(≥1 个) | 平均军功 | 当局介入 | 签了屈辱约 |
|---|---|---|---|---|---|---|
| 笔杆子，争外交，策反（缺省） | 4.0 | 0.61 | 0.61 | 3.2 | 0.38 | 0.29 |
| 一开局就是外交 | 3.2 | 0.65 | 0.65 | 2.6 | 0.31 | 0.25 |
| 前线，不谈（只等介入） | 6.0 | 0.72 | 0.72 | 4.7 | 1.00 | 0.19 |
| 后勤（派遣） | 3.5 | 0.75 | 0.75 | 3.3 | 0.24 | 0.16 |
| 前线，乱斗里专打有名额的 | 3.1 | **1.63** | 0.97 | 4.2 | 0.09 | 0.03 |
| 笔杆子，每周 3 仗 | 3.4 | 0.63 | 0.63 | 3.8 | 0.38 | 0.29 |
| 笔杆子，每周 1 仗 | 5.2 | 0.57 | 0.57 | 2.2 | 0.39 | 0.28 |
| 交际调整值 +0 | 4.6 | 0.56 | 0.56 | 3.6 | 0.48 | 0.33 |

**怎么读这张表**：

- 只靠和领头那家谈，名额落袋的概率在 0.55-0.75 之间。去乱斗里专打有名额的旁观馆，收益明显更高，这正是原著闪灵的打法：输名额的是哈根菲尔德、双峰、鸣神、索拉纳西，不是石村（77:33803-33806）。
- 屈辱约的概率在 0.2-0.3，主要来自早早开谈、战局为负的局。玩家可以靠「等战局起来再谈」规避。
- 「只等当局介入」的打法第 6 周才收场。原著是第 3 到 5 周，所以「战争阶段满 3 周后每周 +15」这个数不宜再小。
- **验收区间**（实装后用同一脚本跑真函数）：缺省打法的 P(≥1) 在 [0.5, 0.75]，当局介入率在 [0.25, 0.5]，平均周数在 [3, 5]。
